# cart

## Cart products section

- A collection of product entries.
- Each product entry contains:
  - Product name (including category, sub category and brand).
  - Pack size
  - Price.
  - Quantity.
  - Total price.
  - Delete button.
  - Alter button.

## Cart summary section
- Total before GST.
- Total GST.
- Grand total.
- Proceed to Checkout button.
