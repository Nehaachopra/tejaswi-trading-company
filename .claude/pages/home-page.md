# Home Page Structure 

A single large, edge-to-edge background image of a rice wholesale warehouse.

## Transaction Action Pills

Display the following nine transaction actions:

1. Sale
2. Purchase
3. Receipt
4. Payment
5. Deposit
6. Withdrawal
7. Drawings
8. Returns
9. Other

Each pill must contain:

- A relevant icon prefixed to the transaction label.
- The transaction label.
- A green `+` button at the right end.
